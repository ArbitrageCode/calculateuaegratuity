# 404 Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a branded 404 page at `src/pages/404.astro` that reuses the existing Layout and design tokens.

**Architecture:** Single Astro page file using `Layout.astro` as the wrapper — same pattern as every other page in the project. No new components, no new styles. Astro automatically serves this file for unmatched routes on static hosts (Netlify, etc.).

**Tech Stack:** Astro, Tailwind CSS v4 (custom design tokens in `global.css`)

## Global Constraints

- Reuse `Layout.astro` — no custom nav/footer markup
- Use existing design tokens only: `text-ink`, `text-body`, `text-mute`, `bg-canvas`, `border-hairline`, `font-mono`, etc.
- Dark mode works automatically via layout — no extra work needed
- No new components, no new CSS classes
- Add `noindex` via `<slot name="head" />` — do not add a `robots` prop to Layout

---

### Task 1: Create `src/pages/404.astro`

**Files:**
- Create: `src/pages/404.astro`

**Interfaces:**
- Consumes: `Layout.astro` props — `title: string`, `description: string`, `canonical: string`
- Produces: a static `/404` route served by Astro on any unmatched URL

- [ ] **Step 1: Create the file with this exact content**

```astro
---
import Layout from '../layouts/Layout.astro';
---

<Layout
  title="404 — Page Not Found | UAE Gratuity Calculator"
  description="This page doesn't exist. Return to the UAE Gratuity Calculator."
  canonical="https://uaegratuitycalculator.com/404"
>
  <Fragment slot="head">
    <meta name="robots" content="noindex" />
  </Fragment>

  <section class="bg-canvas py-24 sm:py-36">
    <div class="max-w-3xl mx-auto px-6 text-center">
      <p class="text-[11px] font-mono text-mute uppercase tracking-widest mb-4">404</p>
      <h1 class="text-[32px] sm:text-[40px] font-semibold leading-[1.1] tracking-[-1.5px] text-ink mb-6">
        Page not found.
      </h1>
      <p class="text-[18px] text-body leading-[1.6] mb-10 max-w-xl mx-auto">
        The page you're looking for doesn't exist or has been moved.
      </p>
      <a
        href="/"
        class="inline-flex items-center gap-2 px-5 py-2.5 bg-ink text-on-primary text-sm font-medium rounded-full hover:opacity-80 transition-opacity"
      >
        Go to Calculator →
      </a>
    </div>
  </section>
</Layout>
```
